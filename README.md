# Concept Playgrounds

Small interactive apps that teach a technical concept by letting you play with it.

| Playground | What you learn |
| --- | --- |
| [ontology](ontology/) | What an ontology is: classes, properties, and how a reasoner infers new facts |
| [metric-court](metric-court/) (prototype) | Why two dashboards show different numbers, and how a semantic layer stops it |

Each playground is a self-contained static site in its own folder, deployed to Vercel as its own project with that folder as the root directory.
